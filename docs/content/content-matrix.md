## 1. Модель карточки тренировки (поля `Workout`)

Поля соответствуют модели `Workout` из MVP-ТЗ (раздел 5). Источник истины для seed БД (S1-5).

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `slug` | string (uniq) | Технический идентификатор карточки, латиница-кебаб | `neck-shoulders-release` |
| `title` | string | Название в тоне Soft System | «Мягкая разгрузка шеи и плеч» |
| `goal` | string | Цель / состояние, под которое подходит практика | «Снять зажатость после сидячего дня» |
| `duration_min` | int | Длительность в минутах | `12` |
| `level` | enum: `easy` \| `medium` | Уровень. В MVP только два — без `hard` (нет fitness-агрессии) | `easy` |
| `equipment` | string[] | **Массив** инвентаря. Значения: `без инвентаря`, `коврик`, `резинка`, `МФР-ролл` | `["коврик"]` |
| `is_premium` | bool | `false` = free, `true` = premium | `false` |
| `video_url` | string (placeholder) | Ссылка на видео. **Сейчас placeholder, `TODO`** | `https://placeholder/refiesse/neck-shoulders-release` |
| `description` | string | Короткое описание (1–2 предложения), мягкий тон | «Для тех, кто долго сидел...» |
| `cautions` | string | Осторожности для этой практики (всегда видимы на карточке) | «Если есть острая боль или онемение — не идём через усилие» |
| `category_id` | ref → `Category.slug` | Категория (одна) | `spina` |
| `program` | ref → `Program` (через `ProgramDay`) | В каких планах используется (N—M) | `plan-back-posture-7` |

Правила (из ТЗ):
- `equipment` — **массив** (мультивыбор в онбординге и в карточке); значение `без инвентаря` не комбинируется с остальными.
- `level` в MVP ограничен `easy` / `medium` — намеренно, чтобы не создавать «спортивную» планку.
- premium-карточка без доступа отдаёт метаданные, но **не** `video_url` / контент (ТЗ 4.6, 6).
- блок `cautions` всегда виден (ТЗ 4.4).

## 5. Тексты для Mini App (готовы к вставке, тон Soft System)

### 5.1 Paywall

- **Заголовок:** Идти по системе, а не искать посты
- **Подзаголовок:** Откройте планы, каталог и мягкое движение под ваше состояние — спокойно и в своём темпе.
- **Что входит:**
  - 3 мини-плана на 5–7 дней — маршрут вместо случайных упражнений
  - Premium-каталог мягких тренировок под состояние
  - Избранное, история и отметка «Я сделала»
  - Тренировки без инвентаря и с ковриком/резинкой/роллом — как удобно
- **CTA (основная):** Открыть через Tribute
- **CTA (вторичная):** Продолжить бесплатно

### 5.2 Дисклеймер / осторожности (общий)

> Refiesse Fit — это мягкая практика движения, а не медицинская программа. Здесь нет диагнозов и анкет.
> Если есть острая боль, онемение, головокружение или недавняя травма — не идите через усилие и остановитесь. При хронических состояниях, беременности или после операций сначала посоветуйтесь с врачом.
> Двигайтесь в комфортном диапазоне: приятное ощущение важнее «правильной» амплитуды.

### 5.3 Пустые состояния (empty states)

**Каталог — ничего не нашлось по фильтру:**
> Под этот подбор пока нет тренировок. Попробуйте убрать один фильтр или изменить состояние — мягких вариантов много.

**Каталог — вообще пусто (нет данных):**
> Тренировки скоро появятся здесь. Загляните чуть позже — мы наполняем каталог мягкими практиками.

**Прогресс — ещё ничего не отмечено:**
> Здесь будет ваш путь. Даже 10 минут считаются — начните с одной короткой практики, и она появится в прогрессе. Без давления и без «сгоревших» дней.

**Планы — нет активного плана:**
> Пока вы не идёте по плану — и это нормально. Когда захотите системности, выберите маршрут на 5–7 дней, чтобы не искать упражнения каждый раз.

**Избранное — пусто:**
> Сохраняйте сюда практики, к которым захочется вернуться. Нажмите ♡ на любой тренировке.
