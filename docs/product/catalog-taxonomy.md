# Каталог и теги — финальная таксономия

Источник правды для структуры каталога и системы тегов Refiesse Fit.
Финализировано владельцем/Катей. На основе этого строится модель данных
(Workout + теги), фильтры каталога, редактор в админке и подбор.

## Каталог (категории — «направления»)

Одна тренировка = одна категория (верхнеуровневое направление).

| Emoji | Категория |
|---|---|
| 🧘 | Пилатес |
| 🧍 | Осанка |
| 🩵 | Здоровая спина |
| 🌿 | Растяжка |
| 🔥 | Сила |
| 😌 | Восстановление |
| 🌅 | Разминки |

## Теги (мультивыбор, несколько измерений)

Тренировка может иметь несколько тегов в каждом измерении.

### По зоне
Всё тело · Шея · Плечи · Грудной отдел · Поясница · Пресс/кор · Ягодицы ·
Тазобедренные · Колени · Стопы

### По времени
- 5–10 минут — быстрые решения
- 15–20 минут — самые популярные тренировки
- 25–35 минут — полноценные занятия
- 40–60 минут — интенсивные занятия

*(вычисляется из фактической длительности `durationMin`)*

### По инвентарю
Без инвентаря · Резинка · МФР · Коврик · Гантели

### По месту
Дома · На улице · В зале · В офисе

### По нагрузке (насколько тяжело физически)
Мягкая · Умеренная · Интенсивная

### По уровню
- Начинающим — «я только начинаю заниматься»
- Продвинутый — «я уже уверенно двигаюсь и хочу сложнее»

### Ограничения по нагрузке
Без прыжков · Без опоры на запястья · Щадяще для коленей

## Связанные идеи

### Офисная разминка в боте
Напоминание в боте сделать короткую разминку — для тех, кто работает в офисе.
Опирается на: категорию «Разминки» 🌅 + теги «В офисе» + «5–10 минут». Механика:
сегмент «работаю в офисе» (opt-in в профиле) → планировщик шлёт в рабочие часы
короткую разминку с web_app-ссылкой прямо на нужную тренировку. Расширяет
существующую систему напоминаний (MOTIV-1) новым типом «разминка».
