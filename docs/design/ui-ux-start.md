# Refiesse Fit Mini App — UX/UI старт

Дата: 2026-06-27  
Источник визуального стиля: https://refiesse.ru/

---

## 1. Что берём с сайта

### Настроение

- мягко, спокойно, без фитнес-агрессии;
- ощущение личного сопровождения, а не массового марафона;
- чистый воздух, много белого пространства;
- авторский тон: “сначала база, потом нагрузка”; 
- визуально: wellness + персональный тренер + телесная грамотность.

### Цвета

Из сайта видны основные цвета:

| Назначение | Цвет | Использование в Mini App |
|---|---|---|
| Основной текст | `#1E1E1E` / почти чёрный | заголовки, основной текст |
| Фон | `#FFFFFF` | базовые экраны |
| Лавандовый фон | `#F1EFFF` | мягкие секции, onboarding, profile |
| Салатовый фон | `#D5FFC7` | progress, success, streak, отзывы |
| Фиолетовый акцент | `#8F73EA` примерно | кнопки, активные tab, CTA Tribute |
| Коралловый акцент | `#FF8562` | маленькие labels, premium/free теги |
| Серый текст | `#555555` / `#6A6A6A` | описания, secondary text |

### Типографика

На сайте используется TildaSans/Arial-подобная геометричная sans-serif типографика.

Для Mini App:

```css
font-family: Inter, TildaSans, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
```

Характер:

- крупные uppercase-заголовки на лендинге;
- в Mini App uppercase лучше использовать точечно, иначе будет тяжело на маленьком экране;
- основной интерфейс — дружелюбный, читаемый, без мелкого текста.

### Формы и кнопки

С сайта:

- крупные pill-кнопки;
- тонкая обводка на первичных лендинговых CTA;
- в нижних блоках — фиолетовые pill-кнопки;
- минимальные иконки.

Для Mini App:

- основной CTA: фиолетовая pill-кнопка;
- secondary CTA: белая кнопка с тонкой границей;
- paywall CTA: фиолетовый solid;
- success/progress: салатовый фон.

### Графика

Сайт использует:

- фото Кати;
- мягкие цветные овалы/плашки;
- простые “звёздочки” вокруг hero;
- square-карточки с мягкими углами;
- много воздуха.

Для Mini App:

- можно использовать фото/видео-превью тренировок;
- фоновые овалы и мягкие плашки — аккуратно;
- карточки тренировок делать с большими превью;
- избегать агрессивных fitness-градиентов.

## 2. UX-принципы Mini App

### Главная задача

Пользователь не должен думать “какую тренировку искать”. Он должен быстро выбрать состояние:

```text
Что сейчас нужно телу?
→ спина / шея / поясница / кор / расслабление / всё тело
→ получить тренировку или мини-план
```

### Основной сценарий

```text
Открыла Mini App
→ увидела тренировку дня
→ выбрала состояние
→ открыла карточку
→ начала тренировку
→ отметила “Я сделала”
→ увидела прогресс
```

### Paywall-сценарий

```text
Открыла premium-план
→ поняла, что входит
→ нажала “Открыть доступ через Tribute”
→ оплатила
→ вернулась
→ premium открыт
```

## 3. Навигация MVP

Нижняя навигация на 4 раздела:

1. **Сегодня** — home, тренировка дня, быстрый выбор состояния.
2. **Каталог** — категории, фильтры, тренировки.
3. **Планы** — 5–7-дневные программы.
4. **Прогресс** — выполнено, минуты, streak.

Профиль и подписка — через верхнюю кнопку/аватар.

---

## 4. Экраны MVP

### 4.1 Home / Сегодня

Цель: быстро дать действие на сегодня.

Блоки:

- приветствие;
- статус доступа: Free / Premium до даты;
- “Что нужно телу сегодня?”;
- быстрые категории;
- тренировка дня;
- текущий план;
- мягкий CTA на premium.

### 4.2 Onboarding

Короткий, 3–4 вопроса:

- цель/состояние;
- сколько времени;
- есть ли инвентарь;
- уровень.

### 4.3 Catalog

Блоки:

- search/filter later;
- категории chips;
- карточки тренировок;
- free/premium labels;
- длительность, уровень, инвентарь.

### 4.4 Workout Detail

Блоки:

- видео/превью;
- название;
- кому подходит;
- длительность/уровень/инвентарь;
- осторожности;
- упражнения;
- CTA “Начать”; 
- CTA “Я сделала”.

### 4.5 Paywall

Тон: не давление, а объяснение ценности.

Ключевой текст:

> “Не искать упражнения по ленте, а идти по системе: планы, каталог, прогресс и мягкое движение под цель.”

CTA:

- “Открыть доступ через Tribute”;
- “Что входит”;
- “Продолжить бесплатно”.

### 4.6 Progress

Блоки:

- streak;
- тренировки за неделю;
- минуты;
- прогресс программы;
- последние выполненные.

## 5. UI-компоненты

### Chips категорий

- pill shape;
- light lavender background;
- active: purple background + white text;
- labels: Спина, Осанка, Кор, Поясница, Растяжка, Сон.

### Workout Card

Поля:

- preview image / gradient placeholder;
- label free/premium;
- title;
- duration;
- level;
- equipment;
- small CTA.

### Program Card

Поля:

- title;
- duration: 5/7 дней;
- progress: 3/7;
- goal;
- access state.

### Access Badge

- Free: white/gray;
- Premium: coral or purple;
- Active subscription: green/lime.

## 6. Дизайн-направление v0.1

Название направления: **Soft System**.

Смысл:

> Это не фитнес-каталог. Это спокойная система движения: состояние → план → выполнение → прогресс.

Визуально:

- белая база;
- лавандовые и салатовые мягкие фоны;
- фиолетовый CTA;
- коралловые маленькие labels;
- большие скругления;
- минимум шума;
- карточки с ощущением “бережно и понятно”.
