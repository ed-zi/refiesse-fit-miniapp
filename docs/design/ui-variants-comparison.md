# Refiesse Fit Mini App — сравнение UI-вариантов

Файл с вариантами: `/root/refiesse-miniapp-design/refiesse-ui-variants.html`

Дата: 2026-06-27

---

## Варианты

### A. Soft System

**Суть:** ближе всего к текущему сайту Refiesse: белый фон, лаванда, салатовый, фиолетовый CTA, мягкие карточки.

**Сильные стороны:**
- лучше всего сохраняет бренд сайта;
- выглядит мягко и дружелюбно;
- хорошо подходит под обещание “система, а не хаотичные тренировки”;
- paywall можно сделать спокойным, но продающим;
- понятный MVP без лишней премиальности.

**Слабые стороны:**
- есть риск сделать слишком “лендингово”, если переборщить с крупными hero-блоками;
- на маленьком экране нужно следить за плотностью.

**Лучше всего для:** первого публичного MVP.

---

### B. Telegram Native

**Суть:** максимально практичный интерфейс внутри Telegram: компактнее, быстрее, меньше визуального декора.

**Сильные стороны:**
- быстрее всего считывается;
- лучше всего подходит для ежедневного использования;
- проще реализовать;
- меньше риска перегрузить Mini App;
- хорошо работает для каталога и быстрых действий.

**Слабые стороны:**
- слабее переносит визуальный стиль сайта;
- выглядит более утилитарно и менее “брендово”;
- paywall может казаться менее ценным.

**Лучше всего для:** внутренней beta и быстрого MVP.

---

### C. Premium Wellness

**Суть:** более дорогая, редакционная, спокойная wellness-подача.

**Сильные стороны:**
- лучше продаёт ощущение подписочного продукта;
- более “премиальный” paywall;
- хорошо подходит для лендинга или onboarding;
- визуально отличается от обычных Telegram Mini App.

**Слабые стороны:**
- дальше от сайта по типографике;
- меньше Telegram-native скорости;
- может выглядеть слишком “салонно” для ежедневного инструмента;
- сложнее удержать баланс между красотой и пользой.

**Лучше всего для:** paywall, promo-экрана, premium-программы, но не как весь интерфейс.

---

## Рекомендация

Не выбирать один вариант в чистом виде.

Лучший путь для MVP:

```text
A. Soft System как основа
+ B. Telegram Native для плотности и скорости
+ C. Premium Wellness только для paywall / promo-блоков
```

То есть финальное направление:

## Soft Native

**Формула:**

```text
Refiesse visual style
+ Telegram speed
+ clear subscription value
```

---

## Что фиксируем для следующей итерации

1. Основные цвета оставить от Soft System:
   - white;
   - lavender;
   - lime;
   - purple CTA;
   - coral premium labels.

2. Главный экран сделать компактнее, ближе к Telegram Native:
   - меньше hero;
   - больше быстрых действий;
   - сразу виден текущий план.

3. Paywall сделать ближе к Premium Wellness:
   - спокойный редакционный текст;
   - premium ощущение;
   - но без тяжёлого “luxury”.

4. Каталог делать как Telegram Native:
   - быстрые chips;
   - понятные карточки;
   - минимум декоративного шума.

5. Прогресс делать как Soft System:
   - салатовый success;
   - мягкая мотивация;
   - без давления и наказаний за пропуски.
